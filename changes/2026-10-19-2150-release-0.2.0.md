# Release 0.2.0

## Why

The npm-published 0.1.1 (2026-01-12) shipped a transcript feature that did not
work for memos recorded on modern iPhones and iPads, because the MP4 parser
could not read 64-bit atom sizes. #3 fixed that and #2 fixed a crash on null
`ZPATH` rows; both merged on 2026-10-19/20 after a user asked on #3 for a
release. Users run this server via `npx apple-voice-memo-mcp`, so a merge
alone changes nothing for them until a version is published.

## How

- Bump `package.json` and `package-lock.json` to 0.2.0. Minor rather than
  patch because the `hasTranscript` I/O behavior changed and the CHANGELOG
  had never recorded 0.1.1; this release closes out the stale `Unreleased`
  section as well.
- CHANGELOG gains a 0.2.0 section crediting the two contributors and a
  back-filled 0.1.1 section for the January changes.
- Publishing is the existing `release.yml` on a `v0.2.0` tag.

## Validation

- Full CI on `main` after both merges.
- Preflight gate (non-author Codex review + checks) on this branch.
- After tagging: `npm view apple-voice-memo-mcp version` returns 0.2.0 and
  `npx -y apple-voice-memo-mcp@0.2.0` lists memos with `hasTranscript: true`.
